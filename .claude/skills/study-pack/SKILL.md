# חבילת למידה: סיכום + פודקאסט + מפת חשיבה

על כל קטע קריאה שענת מעלה ומבקשת לסכם, מייצרים **את שלושת התוצרים**, גם אם ביקשה רק אחד מהם. אחר כך מעדכנים את המונחון ואת מעקב הלמידה.

**תיקיית הקורס** (`$D`): `/Users/anatfradin/Library/Mobile Documents/com~apple~CloudDocs/מבוא-לפסיכולוגיה`
**הסקריפטים** (`$K`): `$D/.claude/skills/study-pack/scripts`
**קובץ זמני** (`$S`): תיקיית ה־scratchpad של השיחה.

## 0. לפני שמתחילים

1. **שם בסיס** לכל התוצרים: `<X>-<Y>-<נושא-במקפים>`, למשל `25-29-במה-עוסקים-הפסיכולוגים`. **מתחיל במספרי העמודים** (בקשה של ענת).
2. **גבולות הקטע:** אם ענת כתבה "החל בסעיף ... ועד ...", מסכמים רק את זה. מה שמחוץ לגבולות (מסגרת שכבר סוכמה, סעיף הבא) לא נכנס לסיכום ולפודקאסט.
3. **הסעיף במדריך הלמידה** (`$D/חומרי-מקור/מדריך למידה.pdf`): למצוא איזה סעיף מפנה לעמודים האלה ומה **השאלות המנחות** שלו (`get_toc()` ואז `get_text()` בעמודים של הפרק). השאלות האלה הן מה שהקורס מצפה שענת תבין.
4. **שיעור מוקלט:** לבדוק ב־`$D/שיעורים.md` אם יש שיעור על החלק הזה. אם יש, מה שהמרצה הוסיפה או הדגישה נכנס לסיכום, מסומן 🎓.
5. **המקור צריך להיות ב־`$D/חומרי-מקור/`.** אם הקובץ נמצא בשורש התיקייה, להעביר אותו לשם.

## 1. קריאה

```bash
python3 -I "$K/pdf_tools.py" render "$D/חומרי-מקור/pages X-Y.pdf" "$S/pX-Y"
```

לקרוא **כל** תמונת עמוד (`p1.png`...) עם Read. חילוץ הטקסט (`p1.txt`) מבלבל טורים ומסגרות, אז הוא רק לבדיקת פרטים: שמות, שנים ומספרים. לשים לב למונחים בשולי הדף. אלה המונחים הרשמיים (★).

## 2. סיכום → `$D/סיכומים/<base>.md`

לפי **תבנית הסיכום ב־CLAUDE.md**. בכותרת מקשרים לשני התוצרים האחרים:

```markdown
> **פודקאסט:** [<base>.m4a](../פודקאסטים/<base>.m4a) · **מפת חשיבה:** [HTML](../מפות-חשיבה/<base>.html) · [תמונה](../מפות-חשיבה/<base>.png)
```

הכללים:
- כל מה שלא מהספר (אנלוגיה, דוגמה שלי, טריק זיכרון, ניתוח שלי) **מסומן**.
- טריק זיכרון = **משפט הגיוני** עם משמעות.
- **מסכם, לא מנפח:** לא לשכפל את הספר או את המדריך. טבלאות ואיורים שמבהירים, ותוספות **בתוך** סעיף קיים, לא בסעיף חדש (ראי "תבנית סיכום" ב־CLAUDE.md).
- **בלי** פרטים אישיים מסימן המים.
- **בלי "בבחינה"** בגוף הסיכום. מתמקדים בהבנה. כותרת המלכודות: `⚠️ מלכודות: מה קל לבלבל`.
- **שיוך חוקר או מונח לגישה:** לחפש ב־PDF את כל העמודים שבהם השם מופיע. אם הוא שייך לכמה סעיפים, לרשום את כולם (כלל 9 ב־CLAUDE.md).

## 3. פודקאסט (ברקע, 10–30 דקות)

הסיכום נכתב **לפני** הפודקאסט, כי הוא נכנס כמקור ונותן לפודקאסט את הדוגמאות ואת המלכודות.

1. **להסיר את סימן המים** (מספר זהות, מייל, שם) לפני ההעלאה לגוגל:
   ```bash
   python3 -I "$K/pdf_tools.py" redact "$D/חומרי-מקור/pages X-Y.pdf" "$S/nlm/<base>.pdf"
   ```
2. **לבדוק מה כבר יש במחברת.** ענת לפעמים מעלה בעצמה:
   ```bash
   notebooklm source list --notebook 5c610cfe-ba89-4728-a5a0-34d8176a7179
   ```
   אם העמודים כבר שם, מעבירים `id:<source_id>` במקום להעלות שוב.
3. **להריץ ברקע** (`run_in_background: true`):
   ```bash
   "$K/podcast.sh" "$D/פודקאסטים/<base>.m4a" <default|long> "<הנחיות>" "$S/nlm/<base>.pdf" "$D/סיכומים/<base>.md"
   ```
   - **אורך:** `default` עד כ־6 עמודים. `long` לקטע ארוך, או כשענת מבקשת "בהרחבה".
   - **הנחיות** (בעברית, בלי `"` ובלי `$` בתוך הטקסט):
     > פודקאסט בעברית לסטודנטית בקורס מבוא לפסיכולוגיה של האוניברסיטה הפתוחה, שרוצה להבין את החומר לעומק. התמקדו רק ב<גבולות הקטע>. הסבירו <הנושאים המרכזיים>, עם דוגמה מהספר והרבה דוגמאות מחיי היומיום. הדגישו נקודות שקל להתבלבל בהן: <המלכודות מהסיכום>. השתמשו במונחים בעברית כמו בספר. סיימו בסיכום קצר ובשתיים־שלוש שאלות לחשיבה.
   - **לא לערוך את `podcast.sh` בזמן שהוא רץ.** ה־shell קורא את הקובץ תוך כדי ריצה.
4. **כשהסקריפט מסתיים:** לבדוק שכתוב `DONE` ומה משך הפודקאסט, ושכתוב `copied to Google Drive` (הפודקאסטים נשמרים בדרייב, **לא בגיט**). לשלוח לענת את הקובץ (`SendUserFile`, `display: attach`).

**תקלות:**
- שגיאת 502 או הגבלת קצב: הסקריפט מנסה שוב לבד.
- `Auth`: להריץ `notebooklm login` בטרמינל של ענת. היא מתחברת בדפדפן ולוחצת Enter בטרמינל.
- אם ההורדה נכשלה אבל הייצור הצליח: `notebooklm artifact wait <id> -n <NB>` ואז `notebooklm download audio <out> -a <id> -n <NB>`.

## 4. מפת חשיבה → `$D/מפות-חשיבה/<base>.html` + `.png`

1. לכתוב **מתאר markdown** ב־`$S/outline-<base>.md`:
   - `#` אחד: הנושא והעמודים.
   - `##`: 4–7 ענפים ראשיים, **באותו סדר כמו סעיפי הסיכום**.
   - `###` או `-`: תתי־ענפים. כל עלה **קצר**: `**מונח**: כמה מילים`.
   - לכלול שמות, שנים, מספרים ואחוזים שחשוב לזכור.
   - הענף האחרון: חיבור לשאלות המנחות או לקטעים קודמים, אם יש.
2. לבנות (לפייתון של notebooklm יש playwright):
   ```bash
   ~/.local/pipx/venvs/notebooklm-py/bin/python -I "$K/mindmap.py" "$S/outline-<base>.md" "$D/מפות-חשיבה/<base>" "<נושא> · עמ' X–Y"
   ```
3. **לבדוק את ה־PNG** עם Read: שהטקסט קריא, שהעברית מימין לשמאל, ושאין עלה ארוך מדי. אם צריך, לקצר ולבנות מחדש.

**המתאר שמור בתוך ה־HTML** (בין `<script type="text/template">` לבין `</script>`, אחרי כותרת ה־YAML). תיקיית ה־scratchpad נמחקת, אז כדי לערוך מפה קיימת מחלצים את המתאר משם.
**XMind:** `python3 -I "$K/xmind.py" <outline.md או map.html> "$D/מפות-חשיבה/<base>.xmind" "<כותרת>"`.

ה־HTML אינטראקטיבי: אפשר לקפל ענפים ולעשות זום, אבל הוא צריך אינטרנט. ה־PNG נפתח בכל מקום, גם באייפון.

## 5. עדכונים

- **`$D/מונחון.md`:** כל מונח חדש **בסדר א–ב** (★ למונחי שוליים), עם העמודות: מונח | באנגלית | במשפט אחד | **דוגמה** | איפה מוסבר | עמ' בספר.
  - **הדוגמה:** קצרה ומוחשית. עדיף דוגמה מהספר או מהמדריך, מסומנת 📖. אם אין, דוגמה שלי מחיי היום־יום. "—" רק כשאין דוגמה הגיונית (ארגון, תקופה).
  - חוקרים נכנסים לטבלה הנפרדת, בלי עמודת דוגמה.
  - תחום התמחות: השאלה לדוגמה מהטבלה בספר.
  - להוסיף את הסיכום לרשימת "קבצי סיכום".
- **`$D/מעקב-למידה.md`:** שורה בטבלת הסעיפים עם קישורים לסיכום, לפודקאסט ולמפה. שורה ביומן המפגשים.
- אם הקטע שייך לפרק חדש, לעדכן גם את מפת הקורס.
